# Mac QQ 实聊验收记录（2026-10-13）

被测版本：2.0.1。发送客户端：Mac QQ（主人账号）；接收端：firefly / Docker NapCat。消息通过 Mac QQ 原生界面发送，回复在同一聊天窗口读取，并与机器人日志、带 E2E 标记的数据库记录交叉核对。

测试前在本机 Docker 数据卷备份数据库。测试文本和色块图片为合成数据，不发送其他联系人或群聊。

## 已验证

| 项目 | 实际结果 | 状态 |
| --- | --- | --- |
| `/status` | 客户端收到当前模型、问答轮数、好友私聊及 Agent 2.0 状态 | 通过 |
| `/help` | 收到用户命令与主人模型管理命令 | 通过 |
| `/models` | 收到 primary 模型列表及图片能力配置 | 通过 |
| 无效模型 | `/model e2e_missing` 返回模型不存在，不改变会话 | 通过 |
| 未知命令 | `/e2e_unknown` 返回命令无效及帮助入口 | 通过 |
| 普通聊天 | 确认测试代号“蓝莓731”，自然问候 | 通过 |
| 连续追问 | 后续提问准确返回“蓝莓731” | 通过 |
| 计算 | 实际调用 calculate，客户端收到 `2400`，日志显示 2 次模型请求、1 次工具调用，4.9 秒 | 通过 |
| 时间 | 实际调用 current_time，回复北京时间 2026-10-13、星期二，4.2 秒 | 通过 |

| 等待提示 | 联网期间收到一次符合实际阶段的等待提示 | 通过 |

| 登录恢复 | 用户重新登录后程序自动重连，重测搜索收发成功 | 通过 |

## 尚待实聊验证

- 图片识别、图文同条与图片引用。
- 普通文字引用、机器人答案引用。
- `/cancel` 中止当前及排队任务，确认无迟到回答。
- 撤回正在处理的测试提问，确认任务与本地上下文处理。
- `/reset` 清空测试上下文，以及模型切换后的会话行为。
- Markdown 排版、长回答分段、文件附件的明确不支持提示。

上述待验证项目不能依据已有模拟测试标记为实聊通过。

## 运行限制
