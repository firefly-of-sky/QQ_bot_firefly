# 2026-11-01 QQ 掉线调查

时间均为北京时间（UTC+8）。调查时线上版本仍为 QQbot 5.0.0。

## 结论

直接断线原因是 QQ 内核报告当前登录身份失效；NapCat 收到通知后重启其 QQ Worker，随后快捷续登也因身份失效被拒绝，转为等待手机扫码。不是服务器重启、Docker 容器退出或内存不足造成的中断，也没有发现模型执行退出账号或修改在线状态的记录。

这只能确认登录身份失效，不能进一步确认是谁或何种策略使其失效。`KickedOffLine` 是 QQ 内核事件名称，不能单凭名称断言账号被处罚、风控、异地登录，或把责任归于某个服务端策略。现有通知没有提供更具体的失效原因。
